6주차. 도구 적용하기 (3): 무역 데이터

1 양자간 무역 데이터

1.1 UN Comtrade 데이터

  • 세계 최대 규모의 무역 통계 DB: 유엔(UN) 통계국이 운영하며, 전 세계 국가들의 상세한 상품별 수출입 실적(연간/월간)을 집계해 제공

  • 분류 체계: HS(Harmonized System), SITC(Standard International Trade Classification), BEC(Broad Economic Categories) 등 다양한 국제 상품 분류 기준을 지원

  • 데이터 접근 및 다운로드: 공식 웹사이트

1.2 CEPII 데이터

  • 프랑스 파리에 위치한 국제경제 연구기관인 CEPII(Centre d’Études Prospectives et d’Informations Internationales)에서 실증 국제무역 및 세계 경제 분석을 위한 고품질 표준 데이터베이스를 제작·배포

  • 연구 목적에 따라 몇 가지 데이터셋으로 나누어져 있음

  • BACI (Base pour l’Analyse du Commerce International)

    • UN Comtrade의 원자료를 정교하게 보정 및 조화(Harmonization)하여 구축한 세계 양자간 무역 DB

    • Comtrade의 문제점인 수출국 보고액과 수입국 보고액 간의 불일치를 통계적 가중치 알고리즘으로 조정하여 단일화된 거래 데이터 제공

    • HS 6자리 수준의 데이터로 제공되어 미시적인 산업 분석에 적합

    • 데이터 접근 및 다운로드: 공식 웹사이트

  • Gravity 데이터

    • 표준적인 중력모형 (Gravity model of trade)을 추정하기 위한 통합 데이터셋

      • 중력모형 추정에 필요한 독립변수와 종속변수를 하나의 데이터셋에 결합되어 있어 별도의 매칭 작업을 최소화

    • 양자간 무역액, 거리, 국경 인접 여부,역사적 및 문화적 유대, 제도적 및 정책적 변수, 거시지표 등을 포함

    • 강의 시점에서 가장 최근 데이터는 2022년에 업데이트된 데이터임

    • 데이터 접근 및 다운로드: 공식 웹사이트

1.3 실습 데이터

  • 이번 주 실습을 위하여 CEPII의 Gravity 데이터와 BACI 데이터의 일부를 강사가 추출하여 별도의 csv 파일로 아래에 제공함

  • 만약 공식 웹사이트에서 직접 다운로드한 데이터를 R에 불러오는 경우에는 파일이 크기 때문에 data.table::fread()를 사용하는 것이 편리함

    • fread()는 대용량 텍스트 파일을 빠르고 효율적으로 읽기 위한 함수

    • 이렇게 읽은 데이터는 기존의 데이터 프레임과 호환성을 유지하므로 지금까지 데이터 프레임을 다루었던 방법을 그대로 사용할 수 있음

2.2 수출국 보고액과 수입국 보고액 사이의 불일치

  • UN Comtrade 데이터는 각국 정부가 보고한 통계에 의존하기 때문에 한국이 보고한 수출과 상대국이 보고한 수입에 차이가 있을 수 있음
    • CEPII Gravity 데이터도 UN Comtrade 데이터에 기초하므로 동일한 문제가 있음
    • gravity_small.csv 데이터에서는 tradeflow_comtrade_o가 수출국이 보고한 금액이고 tradeflow_comtrade_d가 수입국이 보고한 금액임
  • 이러한 불일치를 거울 데이터 불일치 (Mirror Discrepancy)라고 부름
    • 불일치가 발생하는 한 가지 이유로는 통상적인 통계에서 수출액은 FOB 가격, 수입액은 CIF 가격을 채택하는 데에서 찾을 수 있음
    • 그 외에 다른 이유를 생각해 보시오
  • 우리나라 보고 수출액과 상대국 보고 수입액의 비교
    • 만약 거울 데이터 불일치가 FOB/CIF 가격 때문이라면 상대국 수입액이 우리나라 수출액보다 클 것으로 예상됨
    • 이러한 예측이 데이터에서 확인되는지 설명하시오
    • df_kor_2020에 포함된 상대국 중 아래 그래프에 나타나지 않는 국가는 모두 몇 개나 있고 어떤 국가들인지 간단히 설명하시오
      • 우리나라의 수출액이 보고되지 않은 상대국은 몇 개인가?
      • 우리나라로부터의 수입액이 보고되지 않은 국가는 몇 개인가?
      • 우리나라의 수출액과 상대국의 수입액이 모두 보고되지 않은 경우는 몇 개인가?

\[HHI = \sum_{i=1}^{n} s_i^2\]

2.4 중력모형의 기본 형태

2.4.1 무역의 중력모형 (Gravity model of trade)

  • 물리학의 만유인력 법칙에서 착안하여 두 국가 간의 무역량이 경제 규모 (GDP)에 비례하고 거리에 반비례한다는 관계를 설명하는 실증 분석 모형

\[ \text{Trade}_{ij} = \frac{ \text{A} \times \text{GDP}_i \times \text{GDP}_j}{\text{Dist}_{ij}} \]

또는

\[ \ln(\text{Trade}_{ij}) = ln(\text{A}) + ln(\text{GDP}_i) + \ln(\text{GDP}_j) - ln(\text{Dist}_{ij}) \]

3.1 데이터 소개

  • BACI 데이터

    • UN Comtrade 데이터를 바탕으로 국가별 통계 신고의 신뢰도를 평가하여, 수출입 미러 데이터를 통계적으로 정교하게 일치(Reconciliation)

    • HS 6자리 기준의 상세한 품목 분류

    • BACI 데이터의 개별 관측치는 수출국-수입국-품목-연도의 조합임

      • 예를 들어, 2017년 한국이 미국으로 품목 870323을 수출한 금액이 하나의 관측치임

  • HS 코드 (Harmonized System Code)

    • 전 세계에서 거래되는 각종 상품의 종류를 일정한 번호로 분류하여 통일한 국제통일상품분류체계

    • 관세 부과와 무역 통계의 표준화를 위해 세계관세기구(WCO)가 제정

    • 계층적 구조: 숫자가 길어질수록 더 구체적인 상품을 의미

      • 2자리 (Chapter): 87 - 철도용, 궤도용 차량을 제외한 육상 운송수단 및 그 부품
      • 4자리 (Heading): 8703 - 사람을 수송하기 위해 설계된 승용차 및 기타 주행용 모터 차량 (캠핑용 자동차 등 포함)
      • 6자리 (Subheading): 8703.23 - 불꽃점화식 왕복 피스톤 내연기관을 탑재하고, 배기량이 1,500cc 초과 ~ 3,000cc 이하인 승용차

    • HS 코드가 주기적으로 개정되므로 과거 기준을 선택하면 긴 기간의 데이터를 사용할 수 있으며 최근 기준 HS를 사용하면 가용 데이터의 시간 범위가 줄어듬

  • 실습에서 사용할 데이터

    • 이 강의에서 활용한 BACI 데이터는 HS 1992를 기준으로 1995~2024년을 포함

    • baci_kor_import.csv는 원자료에서 한국의 수입을 나타내는 관측치를 추출하여 하나의 데이터에 1995~2024년을 묶어 놓았음 (즉, 원자료에서 j가 410인 관측치를 추출하고 모든 연도를 통합한 것)

      📥 baci_kor_import 데이터 다운로드

    • baci_kor_import_hs2.csv는 baci_kor_import.csv를 각 연도의 HS 코드 2자리로 합계한 데이터

      • 다른 품목 사이에 변수 q의 합계는 의미가 없으므로 이 데이터에서는 제외함

      📥 baci_kor_import_hs2 데이터 다운로드

Variable Description
