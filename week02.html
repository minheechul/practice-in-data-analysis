2주차. 도구 배우기 (2): 데이터 변형하기

1 작업 방식

  • R 스크립트 한 줄씩 실행 (Run): Ctrl + Enter

  • R 스크립트 전체를 실행 (Source): Ctrl + Shift + Enter

    • 보통 R 스크립트를 제출하기 전에 Ctrl + Shift + F10와 Ctrl + Shift + Enter를 이어서 실행하여 원하는 결과가 나오는지 확인
    • Ctrl + Shift + F10: R 다시 시작 (Environment의 객체 및 패키지를 초기화; 객체가 초기화되지 않으면 1주차 RStudio Options 변경이 되었는지 확인)
    • Ctrl + Shift + Enter: 스크립트 전체를 실행

  • 콘솔 (Console) 창에서 실행

2 지난 주 R 스크립트에 대한 부가 설명

  • 함수 (Function): 특정한 작업을 수행하는 명령어로 인자(argument)를 괄호 안에 넣으면 작업을 수행한 결과물을 보여줌

    • 함수이름(인자1, 인자2, ...)의 형식
    round(3.141592, digits = 2)

  • 할당 연산자 (Assignment operator) <-: 오른쪽의 값이나 연산결과를 왼쪽에 있는 변수에 할당 (Alt + -)

    • 새로운 객체를 만들거나 값을 대체할 때 사용
    x <- round(3.141592, digits = 2)
x     # 또는 print(x)

    • 객체의 값을 확인하려면 객체 이름을 입력하거나 print 함수를 이용

    • 대신 =을 대신 사용할 수도 있지만 혼동을 막기 위해 <-를 사용하는 것이 바람직하며, 우리 강의에서는 함수 안에서 인자의 값을 부여할 때만 =를 사용

  • 수치형 (Numeric) 자료와 문자형 (Character) 자료

    one <- 1
two <- "Two"
one + two

  • 파이프 연산자 (Pipe operator) |>: 왼쪽의 결과값을 오른쪽 함수의 인자로 전달 (Ctrl + Shift + M)

  • 비교 연산자 (Comparison operators)

    연산자 의미
    == 같다
    != 같지 않다
    < 작다
    > 크다 
    age <- 25
age != 18
age >= 20

  • R은 문법 규칙만 깨지지 않는다면 공백과 줄바꿈의 개수에 영향을 받지 않음

    • 스크립트를 읽기 쉽도록 공백과 줄바꿈을 적절하게 활용

    • R 해석기는 한 줄이 문법적으로 문제가 없으면 명령이 끝난 것으로 판단하므로 |>, + 등의 위치에 주의

    df2007 <- gapminder
  |> filter(year == 2007)

3 데이터 변형하기: dplyr 핵심 동사

이번 시간에는 데이터를 원하는 형태로 바꾸는 데 가장 자주 쓰이는 dplyr 패키지의 동사(verb)들을 배웁니다.

  • select(): 필요한 변수(열)만 선택
  • filter(): 조건에 맞는 관측치(행)만 선택
  • arrange(): 관측치를 특정 변수 기준으로 정렬 (desc()로 내림차순)
  • mutate(): 기존 변수를 이용해 새로운 변수 생성
  • group_by() + summarize(): 집단별로 나누어 요약통계 계산

이 동사들은 모두 |>로 연결하여 하나의 흐름으로 작성할 수 있습니다.

dplyr 핵심 동사들을 그림으로 비교

  • filter
  • mutate
  • summarize
  • group_by + summarize

4 R 스크립트 예제

# ============================================================
# [Practice in Data Analysis] 2주차 스크립트 예제1
# 학번: **********
# 이름: XXX
# 날짜: 2026-XX-XX
# ============================================================


# ============================================================
# 1. 환경 준비 ---------------------------------------------------
# ============================================================
# 아래 세 패키지는 이 수업의 모든 연습에 항상 사용합니다.
library(tidyverse)
library(janitor)
library(skimr)

# ============================================================
# 2. 데이터 불러오기 ---------------------------------------------
# ============================================================
# 1주차와 동일하게 gapminder를 사용합니다.
library(gapminder)

# ============================================================
# 3. 데이터의 기본적 특성 파악 -------------------------------------
# ============================================================
skim(gapminder)

# ============================================================
# 4. 데이터 변형 --------------------------------------------------
# ============================================================

# 4.1 select(): 필요한 변수만 남기기 -----------------------------------
df_small <- gapminder |>
  select(country, year, lifeExp)

skim(df_small)

# 4.2 filter(): 조건에 맞는 관측치 선택 --------------------------------
df_korea <- gapminder |>
  filter(country == "Korea, Rep.")

df_recent <- gapminder |>
  filter(year >= 2000)

# 4.3 mutate(): 새로운 변수 생성 --------------------------------------
df_gdp <- gapminder |>
  mutate(
    gdp_total   = gdpPercap * pop,
    gdp_billion = gdp_total / 1e9
  )

# 4.4 arrange(): 관측치 정렬 ------------------------------------------
df_2007_sorted <- gapminder |>
  filter(year == 2007) |>
  arrange(desc(lifeExp))

df_2007_sorted

# 4.5 group_by() + summarize(): 집단별 요약 ----------------------------
continent_summary <- gapminder |>
  filter(year == 2007) |>
  group_by(continent) |>
  summarize(
    n_countries  = n(),
    mean_lifeExp = mean(lifeExp),
    mean_gdp     = mean(gdpPercap)
  )

continent_summary

# ============================================================
# 5. 시각화 및 표 작성 ---------------------------------------------
# ============================================================

# 대륙별 평균 기대수명 막대그래프
p1 <- ggplot(continent_summary, aes(x = continent, y = mean_lifeExp)) +
  geom_col() +
  labs(
    title = "대륙별 평균 기대수명 (2007)",
    x = "대륙",
    y = "평균 기대수명 (년)"
  )

p1

# 대륙별, 연도별 평균 기대수명 추이
p2 <- gapminder |>
  group_by(continent, year) |>
  summarize(mean_lifeExp = mean(lifeExp)) |>
  ggplot(aes(x = year, y = mean_lifeExp, color = continent)) +
  geom_line() +
  labs(
    title = "대륙별 평균 기대수명 추이",
    x = "연도",
    y = "평균 기대수명 (년)"
  )

p2
