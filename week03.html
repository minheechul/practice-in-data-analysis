1 지난 시간에 이어서

  • Ctrl + Shift + F10이 객체를 초기화 시키는지에 관한 질문

  • 단축키

    • 할당 연산자 (<-): Alt + -
    • 파이프 연산자 (|>): Ctrl + Shift + M
    • 스크립트 한줄씩 실행: Ctrl + Enter
    • 주석 토글: Ctrl + Shift + C

  • 코드 편집

    • 자동 완성 기능: Tab
    • 줄 위치 이동: Alt + Up/Down

  • 실습실 컴퓨터에 R과 RStudio 최신 버전을 설치 (3주차 강의 종료 직전에)

2 ggplot2 패키지

2.1 구성요소

  • 데이터: 시각화할 원본 데이터프레임

  • 미적 매핑 (Aesthetic mapping, aes()): 데이터의 변수를 시각적 속성 (x축, y축, 크기, 색상, 모양 등)과 연결

  • 기하학적 객체 (Geometries, geom_*): 데이터를 어떤 형태 (점, 선, 막대 등)로 화면에 표현할지 결정

2.2 코드구조

  1. 캔버스 생성: 데이터와 좌표축 설정
  2. 도형 레이어 추가
  3. 보조 레이어 추가
Important주의

이번 주 예제에서 사용된 df2007은 지난 시간 사용한 gapminder 데이터에서 2007년에 해당하는 자료만을 추출한 데이터프레임입니다.

예)

df2007 |> ggplot(aes(x = gdpPercap, y = lifeExp)) +    # 캔버스 생성
  geom_point() +                                       # 도형 레이어 추가
  geom_smooth()                                      # 보조 레이어 추가

3 수치형 변수의 차트

3.1 수치형 변수 1개의 요약

  • 히스토그램 (Histogram)
df2007 |> ggplot(aes(x =lifeExp)) +
  geom_histogram()

df2007 |> ggplot(aes(x =lifeExp)) +
  geom_histogram(bins = 10)  

df2007 |> ggplot(aes(x =lifeExp)) +
  geom_histogram(binwidth = 10)  

df2007 |> ggplot(aes(x =lifeExp)) +
  geom_histogram(breaks = seq(0, 70, by = 10))
  • 상자그림 (Box plot)
df2007 |> ggplot(aes(x =lifeExp)) +
  geom_boxplot()

df2007 |> ggplot(aes(y =lifeExp)) +
  geom_boxplot()

3.2 수치형 변수 2개의 관계 요약

  • 산점도 (Scatter plot)
df2007 |> ggplot(aes(x = gdpPercap, y = lifeExp)) +
  geom_point()

df2007 |> ggplot(aes(x = gdpPercap, y = lifeExp)) +
  geom_point() +
  scale_x_log10()

3.3 참고: ggplot 객체

  • ggplot 차트를 변수에 저장하여 다시 호출할 수 있음
  • 반복적으로 사용하는 레이어를 객체로 만들고 + 연산자로 추가하여 재사용 가능
  • ggsave() 함수로 원하는 파일 형식을 외부 파일로 저장
p0 <- df2007 |> ggplot(aes(x = gdpPercap, y = lifeExp)) +
  geom_point()

p0

p0 + geom_smooth()

4 범주형 변수의 차트

이 섹션의 연습을 위해서 우선 다음과 같이 새로운 범주형 변수 income_group을 만드세요.

df2007 <- df2007 |>
  mutate(income_group = cut(gdpPercap, 
                            breaks = quantile(gdpPercap, probs = c(0, 1/3, 2/3, 1)),
                            labels = c("Low", "Medium", "High"),
                            include.lowest = TRUE
                        )
  )

4.1 범주형 변수 1개의 요약

  • 도수분포표 Frequency table
df2007 |> tabyl(continent)

df2007 |> tabyl(income_group)
  • 막대그래프 (bar chart)
df2007 |> ggplot(aes(x = continent)) +
  geom_bar()

df2007 |> ggplot(aes(x = income_group)) +
  geom_bar()

4.2 범주형 변수 2개의 관계 요약

  • 교차표 (Contingency table)
df2007 |> tabyl(continent, income_group)

df2007 |> tabyl(continent, income_group) |> 
  adorn_percentages("row")

df2007 |> tabyl(continent, income_group) |> 
  adorn_percentages("col")
  • 범주형 변수 2개와 막대그래프
df2007 |> ggplot(aes(x = continent, fill = income_group)) +
  geom_bar()

df2007 |> ggplot(aes(x = continent, fill = income_group)) +
  geom_bar(position = "dodge")

df2007 |> ggplot(aes(x = continent, fill = income_group)) +
  geom_bar(position = "fill")

5 수치형 변수와 범주형 변수를 함께 살펴보는 차트

5.1 범주별로 수치형 변수의 분포 전체를 제시

  • 분할 차트 (Faceting)
ggplot(df2007, aes(y = lifeExp)) +
  geom_boxplot() +
  facet_wrap(~continent)
  • 병렬 상자 그림 (Side-by-side box plot)
ggplot(df2007, aes(x = continent, y = lifeExp)) +
  geom_boxplot()

5.2 범주별로 두 수치형 변수의 관계를 제시

df2007 |> ggplot(aes(x = gdpPercap, y = lifeExp, color = continent)) +
  geom_point()

5.3 범주별로 수치형 변수의 통계량을 제시

gapminder |> group_by(continent) |>
  summarize(mean_lifeExp = mean(lifeExp))     

gapminder |> group_by(continent) |>
  summarize(mean_lifeExp = mean(lifeExp)) |>
  ggplot(aes(x = continent, y = mean_lifeExp)) +
     geom_col()

6 시간에 따른 변화를 나타내는 차트

  • 선그래프 (Line chart)
gapminder |> group_by(year) |>
  summarize(mean_lifeExp = mean(lifeExp)) |>
  ggplot(aes(x = year, y = mean_lifeExp)) +
     geom_line()

gapminder |> group_by(year, continent) |>
  summarize(mean_lifeExp = mean(lifeExp)) |>
  ggplot(aes(x = year, y = mean_lifeExp, color = continent)) +
     geom_line()
